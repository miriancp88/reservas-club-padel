# Permisos y autorizaciones

Qué permisos haría falta tener para ejecutar el proyecto, en el desarrollo académico y en un contexto profesional real.

| Aspecto | En el desarrollo académico | En un contexto profesional real |
|---|---|---|
| Autorización del club | No necesito. No uso instalaciones, datos ni información interna del club: me baso en mi experiencia como jugadora y en datos ficticios. | Acuerdo o contrato con el club que fije qué se desarrolla, quién es responsable y el acceso a las reglas y horarios reales. |
| Datos personales | No hay datos reales: usuarios, pistas, horarios y clases son ficticios. | Cumplir la normativa de protección de datos (RGPD y LOPDGDD): política de privacidad, base legal, medidas de seguridad y contrato entre el club y quien desarrolla. |
| Repositorio y herramientas | Mi cuenta personal de GitHub. El repositorio es público y no contiene datos sensibles, así que el profesorado entra sin permisos especiales. | Repositorio privado de la empresa o del club, con permisos por rol y acceso solo para quien trabaja en el proyecto. |
| Servidores y servicios externos | Cuenta propia en AWS (créditos de cuenta nueva) o en InfinityFree, aceptando las condiciones del servicio. AWS puede pedir un método de pago al crear la cuenta. | Cuenta de hosting y dominio a nombre del club, con facturación y accesos con los permisos mínimos necesarios. |
| Licencias de software | No necesito licencias de pago: XAMPP, PHP, MySQL, Bootstrap, Visual Studio Code y Git son gratuitos o de código abierto, y Figma lo uso con cuenta gratuita. | Revisar las condiciones de cada licencia y valorar planes de pago si el equipo crece. |
| Contenido de terceros | Solo uso textos e imágenes propios o con licencia libre, indicando la fuente. | Licencia o permiso por escrito para logotipos, fotos o textos del club o de terceros. |
| Pagos | No se necesita ninguna: los pagos online están fuera del alcance. | Si se añadieran, haría falta una pasarela de pago y cumplir sus requisitos de seguridad. |
| Pruebas con personas | Pido a una o dos personas que prueben la aplicación voluntariamente, sin recoger sus datos personales. | Consentimiento informado de los usuarios que participen y tratamiento de sus datos según la normativa. |
