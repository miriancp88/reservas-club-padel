# Recursos

## Herramientas (todas gratuitas)

- Visual Studio Code, XAMPP (Apache, PHP y MySQL) y phpMyAdmin, en local.
- HTML, CSS, JavaScript y Bootstrap.
- Git y GitHub (repositorio, ramas, Projects e Issues).
- Figma, para el prototipo de pantallas.
- OneDrive educativo, para las copias de seguridad semanales.
- AWS con créditos gratuitos para publicar (alternativa: InfinityFree).

## Recursos humanos y materiales

- Trabajo propio: unas 111 horas de desarrollo, a unas 12 horas por semana.
- Un ordenador, teclado y ratón externos, y conexión a internet.
- Una o dos personas para probar la aplicación (tarea T13).

## Roles que asumo durante el proyecto

Administradora de sistemas, analista y diseñadora, diseñadora de interfaz, administradora de la base de datos, desarrolladora del servidor, desarrolladora de pantallas, integradora y probadora, y responsable de documentación. La asignación de cada rol a cada tarea está en la tabla de recursos del PDF de la Fase 3.

## Coste

Desembolso real: 0 €. Coste hipotético en un club real: alojamiento (unos 36 USD el primer año), dominio .es (unos 10 € al año desde el segundo) y mantenimiento. Detalle en el PDF de la Fase 3.
